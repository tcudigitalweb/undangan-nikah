Elegant and responsive wedding invitation website built with HTML, CSS, and JavaScript.

## ✨ Features
- Editable content (no coding required)
- Responsive design (mobile & desktop)
- Background music
- Countdown wedding day
- Google Maps integration
- Guest name via URL
- Photo gallery
- Ready for GitHub Pages & Netlify

## 📂 File Structure
index.html
config.js
assets/
LICENSE

## 🛠 How to Edit
1. Open `config.js`
2. Edit names, date, location, and gallery
3. Replace images in `assets/img`
4. Replace music in `assets/music`
